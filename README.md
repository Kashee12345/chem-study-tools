# General Chemistry Study Tools

Animated walkthroughs, virtual labs and problem trainers for general chemistry, Modules 1 to 17.
Each module has an animated Walkthrough (macroscopic, particle and symbolic views together) and a Lab.
Open `index.html` to start. Live: https://kashee12345.github.io/chem-study-tools/
